# WAGWAN Movie

WAGWAN Movie es una aplicación web desarrollada como proyecto académico para visualizar y gestionar contenido relacionado con películas.

## Funcionalidades

- Navegación principal de películas.
- Acceso a dashboard administrativo.
- Login de administrador.
- Listado de películas.
- Registro de nuevas películas.
- Edición de películas.
- Eliminación de películas.
- Estadísticas del dashboard.
- Protección de sesión del administrador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage
- Git
- GitHub
